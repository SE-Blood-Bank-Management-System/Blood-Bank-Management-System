About Blood Bank Management System (BBMS)

Software Engineering Mini-Project • Deliverable Part 1 • Team T9

Project Overview

BBMS is a modern web application engineered to manage critical blood-banking workflows. From initial donor registration and pre-donation medical eligibility screening, to collection, mandatory serology/infection testing (HIV, Hepatitis B/C, Syphilis), component separation, First-Expiry-First-Out (FEFO) inventory management, hospital requisitions (including STAT emergency priority), compatibility cross-matching, and delivery tracking.

Modular Architecture

  • accounts: Custom User model with Role-Based Access Control (Donor, Hospital, Staff, Administrator)
  • donors: Donor profile management, donation history, and pre-screening eligibility questionnaire
  • appointments: Slot reservation, capacity checking, rescheduling, and cancellation
  • inventory: Bag ID tracking, serology test logging, quarantine management, component separation, and FEFO allocation
  • core: Global layout, role-aware navigation, public stock lookup, and shared utilities
