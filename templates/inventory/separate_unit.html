Traceability & Shelf-Life Integrity Rules (SRS BBMS-F-031, BBMS-F-032, BBMS-F-037)
  • Traceability Reference: Each derived child unit receives a globally unique Bag ID and permanently links back to parent Bag ID {{ unit.bag_id }}.
  • Stock Exclusion: Once separated, parent unit {{ unit.bag_id }} transitions to Separated status, preventing double counting in available inventory.
  • Anchored Expiry: Child component shelf lives are anchored to source collection date {{ unit.collection_date|date:"d M Y, H:i" }} (RBC: 42 days, Platelets: 5 days, FFP: 365 days). Separation never rejuvenates expiring blood.
  • Serology Clearance: All verified serology test records (HIV, Hep B, Hep C, Syphilis) are copied to each child component.
